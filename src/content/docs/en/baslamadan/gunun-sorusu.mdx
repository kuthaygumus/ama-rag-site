The output has four parts:

- `QUESTION OF THE DAY`: the question we ask. It is the same on every run.
- `HOW`: how the answer was made. For now it says `bare model, no documents`: the model saw only the question.
- The answer: the text the model writes. There is no source list, because the model got no sources. Once the pipeline
  is built, the chunks it used appear below the answer, for example `[1] hr-leave@2025#3`.
- `LEDGER`: the list of every answer so far. Every run adds one line. When the day ends, it holds the answer from every stop, one under the other.

## Common questions

<FAQ q="Why the same question all day?">
The same question shows what each step does to one answer. Does a step fix the answer, break it, or not change it at all?
One question is still not a measurement. We measure quality with a set of questions on the
[Measuring quality](/en/uretim/kaliteyi-olcmek/) page.
</FAQ>

<FAQ q="Does the model give the same answer every time?">
Yes, with the same prompt on the same machine. On an M-series Mac, `npm run step -- 0` and `npm run question` gave the same answer, word for word.
The repo does this on purpose: `temperature: 0` and a fixed `seed`. You can see small differences on other hardware.
We didn't measure this.
</FAQ>

<FAQ q="The HOW line says “chroma store”, not “bare model”. Why?">
Your `data/` folder still holds the output of earlier steps. `npm run question` picks the most complete pipeline you have.
To start the day again, run `npm run catchup -- 0`. It empties `data/` and resets the vector DB. Then the command asks the model alone again.
</FAQ>

<FAQ q="Where is my guess stored?">
In this browser. In another browser or a private window, the box is empty. The number is never sent anywhere.
</FAQ>

<FAQ q="Where is the ledger kept?">
In the `.cache/question-ledger.jsonl` file, one line per run. `npm run question` shows the last 12 lines.
`npm run catchup` doesn't delete the ledger.
</FAQ>

<Takeaway>Same question, same model. Only what we give the model changes.</Takeaway>
